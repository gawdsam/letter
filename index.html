Write a letter

Fill this in once, get a link, send it to anyone. They’ll open an envelope and watch your words appear.

Works with YouTube, Vimeo, Google Drive (set sharing to “Anyone with the link”) and direct .mp4 links. Any other link shows a button that opens in a new tab.

To italicize just a few words, put them between asterisks, like *this*.

Anyone with this link can read the letter. The letter lives inside the link, so nothing is stored on a server. Change the text above and create a new link whenever you like.
